# Signal on the Sand

An unofficial HH Goa 2026 builder-ID generator by RIFF RAFF. Drop in a photo, answer a few unserious questions, and leave with a downloadable signal card for finding your crew on the sand.

**Live:** https://hh-goa-signal-on-the-sand.subhanumajumder.chatgpt.site/

## The experience

- A hand-illustrated Goa beach world wrapped around a physical, flippable WebGL builder card
- A playful questionnaire that turns build energy, fuel, and rituals into a builder class
- An illustrated export frame with tiny HH Goa objects, festival rails, and Goa-coded color
- Local photo processing: uploaded images stay in the browser and are not sent to a server
- Responsive layouts tuned for desktop, mobile, and short landscape screens
- A public, anonymous experience with no ChatGPT sign-in required

## Built with

- Next-compatible React via [vinext](https://github.com/cloudflare/vinext)
- React 19
- [React Three Fiber](https://r3f.docs.pmnd.rs/) and Three.js
- TypeScript and handcrafted CSS
- Cloudflare Workers-compatible production output

## Run locally

Node.js 22.13 or newer is required.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verify

```bash
npm run lint
npm test
```
